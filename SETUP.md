# AniMonster — запуск и интеграции

## Запуск и данные

Установить зависимости `npm ci`, скопировать `.env.example` в `.env`, затем `npm run dev`. Миграции D1 из `drizzle/` применяются по порядку; локальная база лежит в `.wrangler/state`. На Sites миграции входят в архив публикации.

`.env` исключён из Git и используется только локально. Не создавать одновременно `.dev.vars`: он имеет приоритет. Для опубликованного сайта секреты задаются в среде Sites, а не в локальном `.env`.

Каталог, жанры, описание и полные серии приходят из [API AniLiberty](https://api.anilibria.app/api/docs/v1/). Каталог постраничный, число страниц возвращает API. Статического списка нет. Кэш D1 заполняется из API. AniLiberty остаётся основной озвучкой и работает без токена. Дополнительные русские озвучки загружаются из Kodik, когда задан `KODIK_API_TOKEN`. Токен выдаётся в [партнёрском кабинете Kodik](https://bd.kodik.biz/) и хранится только в серверной среде. Плеер сопоставляет тайтлы по Shikimori ID, отбрасывает субтитры, CAMRip, заблокированные варианты и неизвестные домены. История, опыт и комментарии общие для всех озвучек.

## Аккаунты и роли

Вход и регистрация: email и пароль от 10 символов, максимум 72 байта UTF-8. Bcrypt cost 12, сессии по SHA-256 токена, HttpOnly/SameSite=Lax/Secure в HTTPS. Запись требует того же Origin; попытки входа ограничиваются по хэшам email и IP. Подтверждение email письмом и восстановление пароля пока не подключены.

Новые аккаунты имеют роль user. /admin возвращает 404 всем, кроме admin/moderator. Владелец базы назначает роль по ID существующего аккаунта: `UPDATE users SET role='admin' WHERE id='ID_ПОЛЬЗОВАТЕЛЯ';`. Формы регистрации и профиля не принимают роль из браузера.

OWNER_PREVIEW=true разрешает явно помеченный аккаунт через доверенную идентичность Sites. На текущем приватном сайте есть только владелец; ему доступна админка. Перед расширением аудитории выключить OWNER_PREVIEW. Для обычного аккаунта нажать «Войти в аккаунт». Локально OWNER_PREVIEW выключен.

## Прогресс и рекомендации

История сохраняет серию и позицию каждые 15 секунд, при паузе и уходе. Просмотренная серия: накоплено 80% длительности и достигнуто 90% позиции. Перемотка не прибавляет время; сервер ограничивает прибавку прошедшим временем. За серию начисляется одна единица опыта. Уровень = 1 + floor(опыт / 10). 20 достижений вычисляются из серий, часов, тайтлов и избранного.

Сохранена витрина из пяти любимых тайтлов. Закрытый профиль скрывает коллекцию и историю на сервере. Дата регистрации, уровень и достижения остаются видимыми. Голоса взаимоисключающие; популярность комментария = лайки − дизлайки. Ответы, спойлеры, жалобы, блокировки и модерация сохранены.

Рекомендации используют жанры последних 10 тайтлов истории и избранного, взвешивают частоту и исключают всю историю и избранное. Онгоинги запрашиваются отдельно. Для гостей недельный рейтинг строится по просмотрам AniMonster; при отсутствии данных показан подписанный рейтинг каталога.

DAU/MAU: уникальные аккаунты и гостевые браузеры за день/30 дней, дни UTC. Просмотр учитывается после 30 секунд, один раз на серию, зрителя и день. Это не подсчёт уникальных физических людей.

## Оплата 89 ₽ в месяц

Кнопки открывают модальное окно с [официальным виджетом ЮKassa](https://yookassa.ru/developers/payment-acceptance/integration-scenarios/widget/integration). Для локального подключения заполнить YOOKASSA_SHOP_ID и YOOKASSA_SECRET_KEY в `.env`, перезапустить сервер. PAYMENTS_ENABLED=true уже задан в шаблоне; без обоих ключей приём платежей выключен. PAYMENTS_ENABLED=false — явное отключение. Секрет остаётся на сервере; браузер получает confirmation_token платежа. Для Sites задать эти же переменные среды; опубликованная среда пока оставлена с PAYMENTS_ENABLED=false.

Подписка даёт пины на месяц, продление вручную, без повторных списаний. 1080p не ограничивается: сохранены условия текущего источника. Тестовый профиль не покупает подписку.

Webhook: https://animonster.smoky-globe-3735.chatgpt.site/api/payments/webhook. Сервер повторно получает платёж у ЮKassa, проверяет заказ, пользователя, сумму 89.00 RUB и статус. Повторный webhook не выдаёт второй месяц. Возврат с формы также проверяет статус.

Нужны доступный извне webhook и настройки чеков магазина. Сейчас сайт приватный, реальная оплата без данных магазина не проверена. Тестовые платежи не дают подписку. Возвраты пока не автоматизированы. Публичный доступ и реальный приём денег не включались.

## VK ID — отложено

[Кабинет VK ID](https://id.vk.ru/business/go), [инструкция](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application). Redirect URI: https://animonster.smoky-globe-3735.chatgpt.site/api/auth/vk/callback. После создания приложения нужен VK_CLIENT_ID. PKCE-flow подготовлен; VK отключён и реальным входом не проверен.

## Проверки

TypeScript и production build. HTTP-проверки: регистрация/вход, сессии, права и 404 админки, CSRF, приватность, комментарии, голоса, жалобы, блокировки, избранное, ограничения времени, достижения, рекомендации и жанры. Каталог проверен на первой, второй и последней страницах. У «Героя щита» проверены 25 серий, HLS и полный ответ медиафрагмента с разрешённым CORS. Полное воспроизведение в пользовательском браузере отдельно не подтверждено.
