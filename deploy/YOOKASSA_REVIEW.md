# Подготовка AniMonster к проверке ЮKassa

Страницы для анкеты открыты без входа:

- сайт: `https://animonster.su`
- реквизиты: `https://animonster.su/legal/requisites`
- оферта: `https://animonster.su/legal/offer`
- условия использования: `https://animonster.su/legal/terms`
- Plus и цена: нажать «AniMonster Plus» в шапке или профиле

В карточке продавца и оферте уже описаны услуга, стоимость 89 ₽ за 30 дней,
способ получения цифрового доступа, порядок оплаты и обращения по возврату.
Платёжный экран остаётся выключенным до подключения магазина.

До подачи анкеты внесите реальные данные самозанятого в `/root/animonster/.env.production`:

```dotenv
LEGAL_SELLER_NAME=Фамилия Имя Отчество
LEGAL_SELLER_INN=ИНН
LEGAL_SELLER_ADDRESS=почтовый адрес для обращений
LEGAL_SELLER_PHONE=номер телефона для связи
LEGAL_CONTACT_EMAIL=действующий адрес поддержки
```

Значения указываются без кавычек и должны совпадать с данными анкеты ЮKassa.
Не оставляйте поля пустыми или с шаблонным текстом. Логин и пароль в форме
проверки сайта не требуются: страницы с описанием и документами общедоступны.

После изменения `.env.production` пересоздайте только приложение:

```sh
cd /root/animonster
docker compose up -d --build app
```

Затем проверьте эти ссылки в приватном окне без авторизации. Для включения
платежей после одобрения магазина добавьте его реквизиты `YOOKASSA_SHOP_ID` и
`YOOKASSA_SECRET_KEY`, установите `PAYMENTS_ENABLED=true` и пересоздайте app.
Тестовые платежи оставляйте выключенными в рабочем магазине.
