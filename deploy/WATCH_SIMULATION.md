# Административные отметки просмотров

По запросу владельца: профиль `grilling` (`dbd6dcdb-b35f-46f1-bf44-689a0d59de4f`),
аниме `21` (Ван-Пис), исходно серии 1–213. Первый запуск добавляет серию 214,
далее одну доступную серию каждый час. Это симуляция в БД, видео не воспроизводится.

Работает только на основном сервере через `animonster-watch-simulation.timer`.
`admin_watch_simulations` хранит настройки и время следующего запуска;
`admin_watch_simulation_events` фиксирует добавленные серии. Изменения истории,
рейтинга, журнала и времени следующего запуска выполняются одной транзакцией.
Блокировка строки задания и уникальность просмотров исключают дубли;
повторный ручной запуск раньше срока ничего не добавляет. Пропущенные часы
не компенсируются. Новые серии берутся только из каталога anime_cache.
При отзыве роли admin у инициатора или удалении профиля задание отключается.
Сессии реального плеера, рефералы и ежедневный огонёк не имитируются.

Проверить: `systemctl list-timers animonster-watch-simulation.timer`.
Журнал: `journalctl -u animonster-watch-simulation.service`.
Остановить: `systemctl disable --now animonster-watch-simulation.timer`.
Существующие 213 отметок остаются нетронутыми.
