# Player catalog campaign

The home-page own-player promo contains a public progress bar: 1500 RUB funds each 200-title expansion. This is a new campaign starting from zero, explicitly selected by the user. The database migration records its start time once; subsequent deploys/restarts do not reset the campaign. Existing fundraising goals, purchases and their historical totals retain their original meaning.

Only direct `donation` orders for goal `player`, with `status=succeeded`, `is_test=false`, a real non-preview user and `confirmed_at>=starts_at`, count. Plus/VPN/nickname/pass purchases, old payments, pending/canceled/chargebacked and test payments do not count. Confirmations of orders created before the campaign can count if payment actually confirms after launch. Amounts are aggregated into integer kopecks in PostgreSQL.

Each round is 150000 kopecks. Completed rounds use integer division; current progress uses remainder, so exactly 1500 RUB displays 0/1500 and one funded expansion; 1700 displays 200/1500 with one funded expansion; 3000 displays 0/1500 with two. No order is deleted or reset. Refunds reduce eligible totals. The completion message says "Собрано на N тайтлов. Продолжим?" to distinguish financed catalog additions from actual ingestion. This change does not download/import 200 titles or claim they have already been uploaded.

The same promo shows the supplied patron artwork and a support CTA using the existing direct-donation checkout preselected to player. The minimum accepted donation remains 150 RUB. The bar refreshes every 30 seconds while visible, on focus/return, and on retry. Network errors show unavailability or label last received data; there is no invented fallback total. Disabled payments/closed goals disable the CTA. Public API exposes aggregate amounts only, no donor identities.

Migration 0068 adds permanent `tag:player-catalog-patron` (Меценат) and a payment-backed inventory guard/trigger. A successful new-campaign donation awards one inventory copy automatically, preserving current equipped tags and existing supporter bundles. It can be equipped in profile appearance and renders wherever UserTag is used. Retries and multiple donations cannot duplicate it. A chargeback removes the tag only when no other eligible campaign donation remains, and clears it if equipped; inventory provenance moves to another valid payment if needed. Preview/test/old/other-goal/Plus orders and arbitrary manual grants cannot obtain it. Honorary gold, Исток легенды, Plus and nickname-studio access are unaffected.

Artwork `public/rewards/player-catalog/patron-v1.png` is the user's original PNG, copied unchanged (2159x728 RGBA, 1803756 bytes). No image transformation or replacement was performed. Promo and tag sizing adapt to mobile; decoration does not change navigation or checkout behavior.
