## Доступ и управление

На своей машине открыть SSH-туннель и оставить процесс работающим:

```sh
ssh -N -L 3109:127.0.0.1:3108 root@31.77.14.179
```

Затем открыть `http://127.0.0.1:3109/catalog`. Для других страниц используется тот же локальный адрес. Внешний порт на сервере открывать не требуется. Вспомогательный туннель агента после проверки закрывается.

На сервере:

```sh
docker inspect animonster-seo-f596fd5 --format '{{.State.Health.Status}}'
docker logs --since 10m animonster-seo-f596fd5
docker stop animonster-seo-f596fd5
docker start animonster-seo-f596fd5
```

Остановка контейнера прекращает работу только staging; отдельная база и исходники сохраняются. Обновление действующего сайта и изменение прокси в этом выпуске не выполнялись.
