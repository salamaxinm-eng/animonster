# Генератор пинов и рамок AniMonster

Администратор открывает `/admin/cosmetic-generator` из `/admin`. Генератор вызывает OpenAI Image Edits API на сервере и передаёт референс AniMonster из `public/rewards/generator-reference/` вместе с необязательным загруженным референсом. API-ключ никогда не отправляется в браузер и не сохраняется в базе.

## Запуск

1. Выполнить миграции: `npm run db:migrate` (в Docker — обычный сервис `migrate`). Новая миграция: `0051_cosmetic_generator.sql`.
2. Задать в серверном окружении `COSMETIC_IMAGE_PROVIDER=openai`, `COSMETIC_IMAGE_MODEL=gpt-image-1.5`, `COSMETIC_IMAGE_API_KEY=...`. Можно использовать существующий `OPENAI_API_KEY` вместо отдельного ключа. У аккаунта API должен быть доступ к выбранной модели и включён биллинг API.
3. Перезапустить сервер приложения. Без ключа админка показывает историю, но кнопка генерации недоступна. Платная генерация не выполняется.

Параметры Image Edits API, включая несколько входных `image[]`, PNG и прозрачный фон, сверены с [документацией OpenAI](https://developers.openai.com/api/reference/resources/images/methods/edit). Одно изображение может генерироваться до трёх минут. Две редкости запрашиваются по очереди, поэтому при ошибке второго запроса первый результат сохраняется.

## Работа

Введите аниме, выберите пин или рамку и одну либо обе редкости. Укажите отдельную идею для каждой редкости, если автоматический выбор мотива не подходит. Добавьте свой PNG/JPG/WebP референс при необходимости и нажмите «Сгенерировать». Для четырёх основных франшиз есть разные заранее заданные мотивы двух редкостей; для других название и правило выбора двух разных мотивов передаются модели. Проверьте результат крупно и на своей аватарке, при необходимости повторите генерацию, скачайте PNG.

Исходный ответ модели проходит обработку прозрачности и проверку. Пин сохраняется как PNG 512×512, рамка как PNG 1024×1024 с вырезанным центральным кругом. Миниатюры 128×128 масштабируются ближайшим соседом. Рамка с разорванным кольцом отвергается. Художественное качество и узнаваемость нельзя гарантировать автоматически: администратор просматривает каждый черновик.

«Сохранить в каталог» создаёт предмет в существующей таблице `cosmetics` с доступом `admin`; это **не выдаёт** его пользователям. После публикации укажите ID пользователя и нажмите «Выдать». Повторные публикация и выдача безопасны. Существующий профиль может применять опубликованный и выданный пин или рамку. Полные изображения, миниатюры, исходные запросы и история сохраняются в PostgreSQL, поэтому развёртывание нового контейнера их не теряет.
