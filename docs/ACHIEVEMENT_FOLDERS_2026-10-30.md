# Папки достижений и единый прогресс профиля

Изменения от 30 октября 2026 года, ветка `codex/animonster-pass`.

- Вместо общей папки «Другие аниме» API формирует отдельную папку для каждого `anime_id`, у которого есть достижения. Имена берутся из кэша каталога; при отсутствии записи — из названия в описании достижения. Общие достижения остаются в «Прочее».
- Новые ссылки имеют вид `/profile?section=achievements&folder=anime-20`. Старый `folder=anime` открывает список папок, `folder=one-piece` — папку Ван-Пис. Счётчики папок включают все связанные достижения, в том числе прежние достижения One Piece.
- Причина «20» в профиле: `/api/stats` создавал отдельный набор из 20 условных показателей, а классический профиль дополнительно содержал жёстко заданный знаменатель. Теперь вкладка достижений и оба представления профиля читают общий каталог и его фактические счётчики. Подробности прогресса в профиле также сгруппированы по аниме.
- Скрытая коллекция не раскрывает названия папок и индивидуальный прогресс постороннему посетителю. Чтение статистики не выдаёт достижения и награды. Порядок выдачи наград в собственном каталоге сохранён.
- Изменения не требуют миграции базы.
